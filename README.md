# Music Graph Analytics

Graph-based music recommendation and analytics system built with Neo4j and Cypher to explore relationships between artists, genres, users, and listening patterns.

---

## Overview

This project explores how graph databases can be applied to music recommendation systems and connected data analysis.

Using Neo4j, the application models musical relationships as graph structures, enabling the exploration of:

- Artist connections
- Genre relationships
- User preferences
- Listening behavior
- Recommendation patterns

The project demonstrates how graph traversal and relationship analysis can improve recommendation and discovery systems.

## Architecture

The application uses Neo4j to represent music-related entities and relationships through graph structures.

### Main entities:

- Users
- Artists
- Songs
- Genres
- Listening interactions

### Main concepts:

- Relationship traversal
- Similarity analysis
- Connected data exploration
- Recommendation modeling
- Graph analytics

Cypher queries are used to explore connections between musical preferences and recommendation opportunities.
